An identity broker designed for AI agents, featuring OAuth2 delegation and consent management.

**Why it matters**: As AI agents become more autonomous, securely managing their identities and permissions is critical. This project bridges the gap by providing robust OAuth2 delegation and consent management tailored specifically for agentic workflows.
